# Exposure It Training Hub

The home for all Exposure It Real Estate Media training: role based cards, daily quizzes and shared brand assets.

## Structure

- `makena-quizzes/` Interactive quizzes for Makena's onboarding (first project).
- `roles/` One folder per job: delivery, ops, editing, qc, photographers, virtual-staging, client-success, leadership.
- `brand/` Shared logos, colors and fonts from the Exposure It brand kit.
- `docs/` Build notes, including the Lovable brief for training.exposureit.com.

## Rules for this repo

This repo is public. Never commit client names, addresses, pricing, promo codes, pay or HR details, or owner decisions. Those stay in Notion.

## Branches

`main` is what learners see. Work in progress goes on a branch such as `makena-week-1`.
